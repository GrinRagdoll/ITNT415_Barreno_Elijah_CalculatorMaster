# ITNT415_Barreno_Elijah_CalculatorMaster

A modular, Git-managed Python calculator application featuring custom ASCII art output for academic submission.

---

## Features

* **ASCII Banner Output:** Renders numerical results as large-scale retro terminal digits.
* **Modular Feature Branches:** Follows a strict feature-per-branch workflow with dedicated pull requests.
* **Robust Error Handling:** Validates numeric inputs and safely manages division-by-zero scenarios.

---

## Branch Architecture

* `main` — Base structure and input validation logic.
* `addition_Barreno` — Addition feature implementation.
* `subtraction_Barreno` — Subtraction feature implementation.
* `multiplication_Barreno` — Multiplication feature implementation.
* `division_Barreno` — Division and error-handling implementation.
